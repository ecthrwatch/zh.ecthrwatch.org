私人电子邮件用户名已从 URL 历史中移除

事情经过。 一次后端数据迁移在 /people/ 和 /parties/ 索引页面上引入了 URL slug，其中嵌入了本网站运营者一个个人电子邮件地址的本地部分 （即 @ 之前的部分）。受影响的 slug 在网站上短暂上线。一旦发现该问题，这些 slug 立即被重命名，使本地部分不再出现在任何 URL 中，并且底层的”相关方”数据也被合并，使衍生自电子邮件的 slug 形式不再被使用。

公开记录中的变更内容。 英文和法文公开部署仓库 （ecthrwatch/www.ecthrwatch.org 和 ecthrwatch/fr.ecthrwatch.org） 的 git 历史已被重写 ，以从每次提交的文件路径、文件内容和提交消息中移除受影响字符串的每一处出现。被重写的历史随后被强制推送 至 GitHub。网站本身未受影响——只清理了部署仓库中的历史记录。

原因。 私人电子邮件的本地部分不应出现在网站的公开记录中，前提是运营者并未在该网站上知情地公开此类信息。此次编辑 范围有限：仅移除了一个地址的本地部分；其他内容、归属或事实材料均未被修改。

注意事项。 清理之前历史的旧提交 SHA 在强制推送后最长可达 90 天内仍可通过直接 SHA URL 在 GitHub 上访问，直到 GitHub 的内部垃圾回收 将其移除。互联网档案馆（archive.org）也可能在受影响的窗口期间捕获了受影响的 URL；那里适用单独的撤下程序。

后续的二次失误。 在构建公开 errata 页面本身（即本页面的前身）时，受影响地址的本地部分在起草过程中被无意中重新输入到页面内容中。该错误在几分钟内被发现并修复：页面内容被修改、重新部署，且部署仓库的 git 历史被第二次清理。此条目以其当前形式反映了已纠正的状态。
